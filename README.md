# bodygroupchanger
Системы смена одежды в Garry's Mod.

Для открытия открытия меню, введите команду в консоли: `bodygroupchanger_menu` или напишите в чате `!одежда`.

🔧 [Mantle](https://github.com/darkfated/mantle): для работы системы необходимо использовать эту библиотеку
